# Security

Terminal Manager is a local menu bar app. It reads your Claude Code and Grok
Build session files, inspects your process list, and can send signals to those
processes.

Please **do not** open a public issue for a vulnerability.

- Use [GitHub Security Advisories](https://github.com/ProximoBinks/terminal-manager/security/advisories/new) if you can.
- Otherwise contact [@ProximoBinks](https://github.com/ProximoBinks).

This project does not run a server and does not send session contents anywhere.
A report is still welcome if a change would let the app signal the wrong
process, leak session contents in logs you did not expect, or bypass macOS
privacy prompts in a surprising way.
